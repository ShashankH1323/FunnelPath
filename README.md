# FunnelPath: E-Commerce Behavior & Segmentation

> **Analyzed 100M+ e-commerce user interaction logs to identify highly critical conversion bottlenecks and optimize product funnels.**

---

## 🚀 Overview
This project implements an end-to-end user behavior analysis and recommendation pipeline for large-scale e-commerce platforms. The project processes massive user interaction logs to extract critical business metrics, identify funnel drop-offs, and construct RFM (Recency, Frequency, Monetary) segmentation models to drive targeted strategies.

### 🔧 Tech Stack
* **Languages:** Python
* **Libraries/Frameworks:** PySpark, Pandas
* **Web Framework:** Flask

## 📈 Key Deliverables
1. **Log Processing:** Processed 100M+ raw user interaction logs using PySpark and Pandas, structuring complex sequential data for accurate funnel analysis.
2. **Funnel Analysis:** Mapped key end-to-end user journeys from page views to final purchase, successfully identifying a critical 65% drop-off at the cart stage.
3. **RFM Segmentation:** Implemented advanced RFM segmentation to cluster 1M+ core users and accurately identify highly valuable long-term customer cohorts.
4. **Actionable Insights:** Translated complex behavioral patterns into actionable UI/UX product strategies, projecting a 15% increase in overall checkout conversion.

---

## Dataset Reference

This project uses Alibaba's [User Behavior Data from Taobao for Recommendation](https://tianchi.aliyun.com/dataset/649), which contains user, item, category, behavior type (`pv`, `buy`, `cart`, and `fav`), and timestamp fields across more than 100 million e-commerce interactions.
